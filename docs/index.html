Setup

Live in under two minutes

Everything runs on your machine. No account, no login, no server — the overlay reads public Twitch chat anonymously.

Download & start the server

Clone or download the repo, then run a tiny local web server from the folder:
cd nubcat-chat-pets && python3 -m http.server 8741

Test it in your browser

Open http://localhost:8741/index.html?channel=yourname — send a chat message and watch your cat hop in. Try ?mock=1&debug=1 for a simulated chat demo.

Add it to OBS

Sources → + → Browser, paste the same URL, set width/height to your canvas (e.g. 1920×1080). The background is fully transparent — only cats, labels and bubbles composite onto your stream.

Chat takes over

Viewers appear as they chat, get their own persistent cat in their Twitch color, and can trigger duels, races and boss battles whenever they want.

Settings

Tune it with URL parameters

Everything is configured by adding parameters to the URL you paste into OBS. Combine them like ?channel=yourname&max=60&scale=1.2.

ParamDefaultWhat it does
channel—Your Twitch channel (required, or use mock)
max40Max cats on screen at once
ttl10Minutes of silence before a cat despawns
scale1Global cat size (0.2–3)
speed1Walking speed (0.2–3)
bubblesonSpeech bubbles showing message text
celebrateonMass hops on subs, raids and gift bombs
flipoffFlip cats 180° if they walk backwards on your setup
gamesonMaster switch for all mini games
duelCooldown90Seconds between duels
raceCooldown180Seconds between races
bossHp250Boss hit points (chat damage needed to win)
bossCooldown420Seconds between boss battles
crownSec300How long winners keep their crown
debugoffCheckerboard background + stats HUD for tuning

FAQ

Good questions

Is it really free? What's the catch?
It's free and it runs entirely on your machine. The overlay connects to Twitch's public anonymous read-only chat gateway — no OAuth, no account access, nothing to trust but your own browser.
Does it slow down my stream?
No. It's a lightweight WebGL overlay capped at 40 cats by default (raise with ?max=), particles are hard-capped, and it renders only when OBS shows the source. A 2015 laptop handles it fine.
How do viewers earn points?
Every chat message earns a point. Points tip the odds in duels and show up in the debug HUD. Boss fighters earn bonus points and winners get crowns — all stored locally in the overlay's browser storage.
Can I turn the games off and just have cats?
Yes — add ?games=0 to your OBS URL. You get the pure roaming-cat overlay with hops, hearts and celebration jumps, no game events.
My cats walk backwards. Fix?
Some capture setups mirror the canvas. Add ?flip=1 and they'll face the right way.
The cats aren't showing up in OBS
Make sure the local server is still running in a terminal (python3 -m http.server 8741) and the URL in OBS uses ?channel=yourname exactly. Tick "Shutdown source when not visible" off if you want cats to keep roaming while previewing scenes.
